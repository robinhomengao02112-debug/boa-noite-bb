# Enredo · Histórias Interativas

App gratuito de histórias interativas: você é o protagonista e suas escolhas mudam a história.

- 3 histórias originais com 14 finais diferentes
- Momentos cinematográficos animados (tarjas de cinema, zoom, chuva, pétalas, faíscas, estrelas)
- Personagens com expressões, afinidade que muda o final
- Voltar fala, histórico, modo automático, salvamento automático
- Coleção de finais
- **Criador de histórias**: escreva o roteiro, crie personagens, teste e exporte/importe (.json) para compartilhar
- Funciona offline (PWA, dá para instalar na tela inicial)

## Segurança e privacidade
- Sem anúncios, sem conta, sem login, sem rastreadores
- Nenhum dado sai do aparelho (Content-Security-Policy bloqueia qualquer conexão externa)
- Backup manual em arquivo, se quiser trocar de celular

## Como usar
Abra `historias/index.html` pelo GitHub Pages (`/historias/`) ou por qualquer servidor estático.
No Android: Chrome → ⋮ → **Adicionar à tela inicial**.
